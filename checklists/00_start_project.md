# 00 Start Project Checklist

Complete this before writing the first full draft.

## Scientific Contract

- [ ] One-sentence contract is filled.
- [ ] Paper type is selected: method / system / analysis / benchmark / resource / negative finding / position.
- [ ] Main claim strength is selected: local matched improvement / general method / SOTA / mechanism / resource / negative finding.
- [ ] Evidence burden for that claim is written down.
- [ ] The title names a memorable object or lens.

## Related Work

- [ ] At least 10 close works listed.
- [ ] At least 3 closest works have precise deltas.
- [ ] 2024-2026 fast-moving-area search completed if relevant.
- [ ] No novelty claim uses "first" unless the search is documented.

## Evidence Plan

- [ ] Datasets and splits named.
- [ ] Baselines named and justified.
- [ ] Metrics named.
- [ ] Statistical test / CI plan named.
- [ ] Ablation matrix drafted.
- [ ] Error taxonomy drafted.
- [ ] Compute and cost plan drafted.

## Project Control

- [ ] TODO files initialized.
- [ ] Build command documented.
- [ ] Artifact root selected.
- [ ] Citation audit table created.
- [ ] Residue scan script tested.
