# 10 Claim Evidence Gate

Use this every time the abstract, title, introduction, or main result table changes.

| Question | Pass / Fail | Evidence |
|---|---|---|
| Does the title match the actual contribution? | | |
| Does the abstract claim only what the main paper proves? | | |
| Is the strongest result broad enough for the headline? | | |
| Are baselines current and fair? | | |
| Are settings matched for direct comparisons? | | |
| Is uncertainty reported where the claim needs it? | | |
| Does an ablation isolate each claimed mechanism? | | |
| Does error analysis explain the main failure modes? | | |
| Are negative/diagnostic runs kept out of headline evidence? | | |
| Can a reviewer verify the claim without private notes? | | |

Decision:

- `PASS`: claim and evidence match.
- `REPAIR`: run or add missing evidence.
- `REFRAME`: change paper type or claim scope.
- `BLOCKED`: cannot proceed without user/PI decision.
