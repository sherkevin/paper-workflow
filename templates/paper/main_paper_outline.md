# Main Paper Outline

## Title

`<Named Object>: <Conceptual Operation> for <Problem>`

## Abstract

1. Field practice.
2. Gap / failure mode.
3. Named method or lens.
4. Mechanism.
5. Evidence breadth.
6. Headline result.
7. Mechanistic finding.
8. Durable implication.

## 1 Introduction

- P1: field-level practice and why it matters.
- P2: concrete failure mode.
- P3: central insight.
- P4: method summary.
- P5: evaluation summary.
- P6: three contribution bullets.

## 2 Related Work

- Closest method family.
- Benchmark / evaluation literature.
- Mechanism / analysis literature.
- Safety / reproducibility / resource context if relevant.

Each paragraph should end with a contrast sentence.

## 3 Method

- Problem setup.
- Core object.
- Algorithm / mechanism.
- Complexity or runtime bound.
- Implementation contract.

## 4 Experiments

- Setup.
- Main results.
- Breadth / generalization.
- Ablation.
- Robustness / sensitivity.
- Error analysis.

## 5 Conclusion

One paragraph. Repeat the durable lesson, not every number.

## Limitations

Scope, model/data constraints, reproducibility, misuse. No new results.

## Ethics / Responsible Research

Use venue policy. Be concrete.

## References

Verified only.

## Appendix

Prompts, commands, extra tables, proofs, artifacts, manifest, and full reproducibility details.
