# Open Workflow Notes

Public workflow sources consulted while building this template:

- ACLPUB formatting: https://acl-org.github.io/ACLPUB/formatting.html
- ACL submission / review / citation policy: https://www.aclweb.org/adminwiki/images/e/e7/ACL_Guidelines_for_Submission%2C_Review_and_Citation.pdf
- Manubot: https://manubot.org/
- showyourwork!: https://show-your.work/
- Quarto manuscripts: https://quarto.org/docs/manuscripts/components.html

Distilled use:

- Keep official venue LaTeX / metadata compatibility as the submission authority.
- Borrow versioned, manifest-driven, reproducible project habits from open manuscript workflows.
- Do not make public continuous publishing the default for double-blind submissions.
