# Bitter Lessons From Late-Stage Submission Work

These are the failure modes this template is designed to prevent.

## 1. Do Not Submit A Moving PDF

Never review or hash a PDF while LaTeX is still writing it. Freeze the artifact after the build finishes, then hash and inspect that exact file.

## 2. Appendix References Are Package Dependencies

If the main paper says `Appendix B` or `Appendix D`, reviewers must receive that appendix in the actual upload package. A separate PDF sitting on disk is not enough.

## 3. A ZIP Can Be Present And Still Stale

Supplement ZIPs must be rebuilt after appendix edits. Verify by extracting the ZIP and checking the manifest from the extracted copy.

## 4. Limitations Can Lower The Paper

Honesty is required, but over-confession is harmful. Do not foreground lack of budget, time, unfinished experiments, local lanes, or internal gates. Phrase boundaries as scientific scope.

## 5. Batch-Level Claims Sound Unfinished

Do not write that the method works on "this batch" or "this slice" as the main contribution. Either raise the evidence to the intended scope or change the paper type honestly.

## 6. Table Structure Shapes Reviewer Trust

Tables with run IDs, batch labels, or prose cells read like lab notebooks. Final tables should expose datasets, baselines, metrics, deltas, and uncertainty.

## 7. Citation Errors Are Not Cosmetic

A single fake citation, fake venue, unsupported claim, or unverified arXiv ID can destroy the submission. Citation audit must be explicit.

## 8. AI Trace Is Usually Concrete

Do not accuse text of being AI-generated by vibe. Audit concrete evidence:

- assistant meta-text;
- task-management residue;
- generic filler;
- inconsistent terminology;
- suspicious citations;
- disclosure mismatch.

## 9. Repeated Reviews Must Be Independent

A fresh reviewer should not read old scoreboards or fix themes before scoring. Otherwise the review becomes confirmation-biased.

## 10. Final Metadata Can Be Stale

OpenReview title, abstract, TL;DR, keywords, supplement, and PDF can drift apart. Treat metadata synchronization as part of the package gate.
